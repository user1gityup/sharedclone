## Plan

> ## Plan
> 
> **RESTATEMENT:** Design and build a lightweight OpenRouter proxy/scheduler that discovers free-tier models, rotates requests across them to prevent cold-start timeouts, and integrates into the existing DSH council architecture.
> 
> **APPROACH:** A thin Python wrapper around OpenRouter's API: (1) discovery module fetching `/models` and filtering `pricing.prompt == 0 && pricing.completion == 0`, (2) round-robin scheduler with per-model "last used" timestamps to enforce keep-alive pings, (3) transparent fallback on 429/5xx errors, (4) exposed as either a local HTTP proxy or direct SDK replacement that DSH seats can target via `OPENROUTER_BASE_URL` override.
> 
> **ASSUMPTIONS:** Free models remain zero-cost indefinitely; "warm" means <5min since last request (OpenRouter's typical timeout); DSH can route OpenRouter seats through a custom base URL without code changes; rate limits are standard OpenRouter headers (RPM limit per key, not per model).
> 
> **RISKS:** Free model availability changes unpredictably—discovery must run continuously; excessive keep-alive traffic burns the $20 metered budget; DSH's OpenRouter integration may hardcode endpoints requiring patches.
