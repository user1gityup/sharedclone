> A proxy layer between DSH's OpenRouter seats and the OpenRouter API that pools every available zero-cost model, round-robins requests through them, and pings idle models on a keep-alive cadence so no seat goes cold and times out. > ## Architecture
> 
> ### Three Components, Minimal Surface Area
> 
> **1. Model Discovery (`discovery.py`)**
> - Hits `GET https://openrouter.ai/api/v1/models` with the DSH's existing OpenRouter API key
> - Filters to `pricing.prompt == "0" AND pricing.completion == "0"`
> - Caches the list to disk as JSON (`models_cache.json`) with a TTL — re-fetches every 5 minutes or on proxy start if cache is stale
> - Emits structured entries: `{id, name, context_length, last_used_epoch, status}`
> 
> **2. Scheduler (`scheduler.py`)**
> - Maintains an in-memory priority queue keyed by `last_used_epoch`, ascending
> - On each inbound request, pops the stalest model, sends the request, and on success pushes it back with an updated timestamp
> - Separate keep-alive thread: every 90 seconds, iterates models unseen in >4 minutes and fires a minimal completion (`max_tokens: 1, prompt: "."`) to reset OpenRouter's idle timeout
> - Handle errors via cascading fallback: 429 → next model immediately, 5xx → retry up to 2 more models, model marked `status: degraded` after 3 consecutive failures and skipped for 10 minutes
