User rejects analogies and metaphors in explanations. Stated plainly: "i don't want analogies", after an explanation closed with a house/rented-walls comparison.

**Why:** the analogy adds length without adding information. The user wants the mechanism itself — file names, steps, constraints — not a restatement of it in other terms.

**How to apply:** explain with the concrete facts only: which files, which build step, which API exists or does not. No "it's like...", no comparison framing, no closing metaphor to summarise. Pairs with [[feedback-caveman-mode]] and the global "fix, don't explain" rule.
