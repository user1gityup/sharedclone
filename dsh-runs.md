# DSH saved runs

One line per finished run, from every machine that shares this brain. The full
record stays where it was made, at `~/.dsh/council-runs/<id>.json` on the machine
the line names; this file is what makes the run visible everywhere. Written when
DSH files a run, and again by the brain sync at every session start and DSH
launch, so runs made before a machine joined are picked up too.

Lines are appended, never edited or reordered: the file merges by union, so two
machines writing at once both keep their lines.

## Managing runs (harness 111c359502, 2026-09-27)

- **Agent tool `runs`**, 11 actions: `list`, `show`, `save_preset`, `save_pipeline_preset`, `update_preset`, `duplicate_preset`, `delete_preset`, `rename_run`, `pin_run`, `unpin_run`, `delete_run`. Deletes need `confirm`.
- **UI:** pipeline panel has PresetEditor (new, edit, duplicate, delete, save current) and RunHistory (rename, pin, delete).
- Rename and pin metadata live at `~/.dsh/council-runs/meta/runs-meta.json`. Pruning skips pinned runs.
- A deleted run keeps its line below: the file is append-only by union. The `00000000-...-c1a0` line is a test dummy that was deleted 2026-09-26.
