## DSH council → swarm → council execution contract

This is a gated three-stage DSH pipeline:

1. **Council:** every enabled, reachable council seat reviews the evidence and current implementation, agrees the root causes, and produces one exact implementation plan and swarm DAG. This stage is planning only: no repository writes, commands, builds, commits, or worker launches. Stop at the approval gate.
2. **Swarm:** after the existing two-factor approval, implement the approved plan in parallel waves. Tasks in one wave must have disjoint write sets. Each hosted worker's output must have one named local owner responsible for applying and testing it. Persist successful units so a stopped swarm resumes without repeating completed work. Stop on a failed wave instead of advancing. No real metered model/API probes are allowed for verification.
3. **Final council:** review the actual diff, tests, built libraries, fixture reproduction, partial-run UI, journal/resume behavior, and acceptance criteria. Create bounded corrective swarm units for defects, then re-review. Completion requires council quorum and evidence against the built artifacts.

Every stage must identify participating models, unavailable seats, elapsed time, failures, and resumptions. Existing approval gates remain single-use and cannot be weakened or bypassed.

## Required implementation

### 1. Large-prompt transport

Make Antigravity handle prompts larger than the Windows command-line limit. Inspect the installed `language_server.exe agentapi` interface before choosing the transport.

Prefer file, stdin, RPC, or native conversation context if supported. If `agentapi` fundamentally requires the final prompt in argv, add a seat-specific prompt-budget system that creates a self-contained prompt below the measured safe limit.

Never silently truncate. Preserve the objective, hard constraints, required output, agreed plan, essential evidence, and citation identifiers. Record omitted material and the reason. Do not split one logical request into independent calls unless tested continuation preserves context.

### 2. Cancellation correctness

Before spawning a CLI child or starting an HTTP request, check `signal.aborted`. If cancelled, start nothing and return a normalized, readable reason such as `cancelled by user`, `run stopped`, `host shutdown`, or `deadline exceeded`.

After spawn, cancellation must terminate the full descendant process tree on Windows. Fix error normalization so objects such as `{"kind":"user"}` never become user-facing messages.

### 3. Timeout design

Separate startup, stream-idle, seat-overall, council-round, and full-run deadlines. A slow seat must not hold every round indefinitely. Do not merely raise all timeouts.

Persist the exact timeout source, for example:

- `seat overall deadline exceeded after 180000ms`
- `stream idle for 60000ms`
- `council round deadline reached`
- `run cancelled by user`

Honor seat-specific timeouts consistently across CLI and OpenRouter transports.

### 4. Partial-result policy

Add explicit terminal states: `completed`, `partial`, `cancelled`, `failed`, and `awaiting_resume`.

A multi-seat council below its configured draft or review quorum must not be reported as a completed council decision. Preserve successful answers and all failures, skip meaningless review, expose a resumable state, and never call one draft a council verdict. Add configurable quorum settings with safe defaults.

### 5. Durable resume

Extend the journal to persist run ID, phase, exact prompt identity, model/transport identity, successful replies, terminal failures, retryable failures, cancellation/timeout reasons, and quorum state.

On resume:

- recall valid successful replies;
- call only unfinished or retryable seats;
- do not retry unchanged configuration errors;
- invalidate answers when the effective prompt, model, transport, or relevant context changes;
- retain the journal until true completion or explicit Start over;
- Stop must not discard useful completed replies.

### 6. Observability

Before each seat call, persist total prompt characters and UTF-8 bytes, sizes of query/plan/evidence/memory, selected transport, seat limit, and whether compaction occurred. Expose these in the run record and report. Never log credentials.

### 7. UI

The Council Budget/pipeline UI must distinguish running, waiting on slow seats, quorum unavailable, partial/resumable, cancelled, failed, and completed. Show each seat as succeeded, failed, timed out, cancelled, or never started. Continue must retry only unfinished/retryable work.

```typescript
import { PromptBudgetConfig } from './seats';

export interface CompactedPrompt {
  prompt: string;
  originalChars: number;
  finalChars: number;
  compactionApplied: boolean;
  omittedSections: OmittedSection[];
  mandatoryRetained: string[];
}

export interface OmittedSection {
  section: string;
  originalChars: number;
  reason: 'size-limit' | 'strategy-truncation';
  retainedSummary?: string;
}

const SECTION_DELIMITERS = {
  objective: /(?:^|\n)#+\s*OBJECTIVE\s*\n/i,
  constraints: /(?:^|\n)#+\s*CONSTRAINTS\s*\n/i,
  'required-output': /(?:^|\n)#+\s*REQUIRED\s+OUTPUT\s*\n/i,
  plan: /(?:^|\n)#+\s*PLAN\s*\n/i,
  evidence: /(?:^|\n)#+\s*EVIDENCE\s*\n/i,
  memory: /(?:^|\n)#+\s*MEMORY\s*\n/i,
  citations: /(?:^|\n)#+\s*CITATIONS\s*\n/i,
};

export function compactPromptForArgv(
  fullPrompt: string,
  budget: PromptBudgetConfig,
): CompactedPrompt {
  const originalChars = fullPrompt.length;
  const maxChars = budget.maxArgvChars - budget.reserveChars;
  
  const sections = parseSections(fullPrompt);
  const mandatoryRetained: string[] = [];
  const omittedSections: OmittedSection[] = [];
  
  // Start with mandatory sections
  let workingPrompt = '';
  for (const key of budget.mandatorySections) {
    if (sections[key]) {
      workingPrompt += formatSection(key, sections[key]);
      mandatoryRetained.push(key);
    }
  }
  
  // Add evidence if space permits (truncated if needed)
  if (sections.evidence && !budget.mandatorySections.includes('evidence')) {
    const evidenceBudget = maxChars - workingPrompt.length - 500; // reserve for footer
    if (evidenceBudget > 1000) {
      const truncatedEvidence = truncateEvidence(sections.evidence, evidenceBudget);
      workingPrompt += formatSection('evidence', truncatedEvidence.text);
      if (truncatedEvidence.wasTruncated) {
        omittedSections.push({
          section: 'evidence',
          originalChars: sections.evidence.length,
          reason: 'size-limit',
          retainedSummary: `${truncatedEvidence.retainedChars} of ${sections.evidence.length} chars`,
        });
      }
    } else {
      omittedSections.push({
        section: 'evidence',
        originalChars: sections.evidence.length,
        reason: 'size-limit',
      });
    }
  }
  
  // Add memory if space permits
  if (sections.memory && !budget.mandatorySections.includes('memory')) {
    const memoryBudget = maxChars - workingPrompt.length - 200;
    if (memoryBudget > 500) {
      const summarized = summarizeMemory(sections.memory, memoryBudget);
      workingPrompt += formatSection('memory', summarized);
    } else {
      omittedSections.push({
        section: 'memory',
        originalChars: sections.memory.length,
        reason: 'size-limit',
      });
    }
  }
  
  // Final validation
  const finalPrompt = workingPrompt + formatOmissionFooter(omittedSections, originalChars);
  const finalChars = finalPrompt.length;
  
  if (finalChars > maxChars) {
    // Emergency truncation - should not happen with proper math
    throw new Error(`Prompt budget calculation error: ${finalChars} exceeds ${maxChars}`);
  }
  
  return {
    prompt: finalPrompt,
    originalChars,
    finalChars,
    compactionApplied: omittedSections.length > 0 || finalChars < originalChars,
    omittedSections,
    mandatoryRetained,
  };
}

function parseSections(prompt: string): Record<string, string> {
  const sections: Record<string, string> = {};
  const keys = Object.keys(SECTION_DELIMITERS) as (keyof typeof SECTION_DELIMITERS)[];
  
  // Find all section boundaries
  const boundaries: {key: string; index: number}[] = [];
  for (const key of keys) {
    const match = SECTION_DELIMITERS[key].exec(prompt);
    if (match) {
      boundaries.push({key, index: match.index});
    }
  }
  
  // Sort by position
  boundaries.sort((a, b) => a.index - b.index);
  
  // Extract sections
  for (let i = 0; i < boundaries.length; i++) {
    const start = boundaries[i].index;
    const end = i < boundaries.length - 1 ? boundaries[i + 1].index : prompt.length;
    const content = prompt.slice(start, end).trim();
    // Remove the header line itself from content
    const headerMatch = /^#+\s*\w+[\s\w]*\n/i.exec(content);
    if (headerMatch) {
      sections[boundaries[i].key] = content.slice(headerMatch[0].length).trim();
    } else {
      sections[boundaries[i].key] = content;
    }
  }
  
  // Content before first section is "preamble"
  if (boundaries.length > 0 && boundaries[0].index > 0) {
    sections.preamble = prompt.slice(0, boundaries[0].index).trim();
  }
  
  return sections;
}

function formatSection(key: string, content: string): string {
  const header = key.toUpperCase().replace(/-/g, ' ');
  return `\n\n## ${header}\n\n${content}`;
}

function truncateEvidence(evidence: string, maxChars: number): {text: string; wasTruncated: boolean; retainedChars: number} {
  if (evidence.length <= maxChars) {
    return {text: evidence, wasTruncated: false, retainedChars: evidence.length};
  }
  
  // Try to truncate at citation boundary
  const citationPattern = /\[\d+\]/g;
  let lastSafeBreak = 0;
  let match;
  
  while ((match = citationPattern.exec(evidence)) !== null) {
    if (match.index < maxChars - 50) {
      lastSafeBreak = match.index;
    } else {
      break;
    }
  }
  
  const truncatePoint = lastSafeBreak > 100 ? lastSafeBreak : maxChars;
  const truncated = evidence.slice(0, truncatePoint);
  
  return {
    text: truncated + `\n\n[... ${evidence.length - truncatePoint} chars omitted: evidence truncated to fit seat limit ...]`,
    wasTruncated: true,
    retainedChars: truncatePoint,
  };
}

function summarizeMemory(memory: string, maxChars: number): string {
  const lines = memory.split('\n');
  const kept: string[] = [];
  let chars = 0;
  
  for (const line of lines) {
    if (chars + line.length + 1 <= maxChars) {
      kept.push(line);
      chars += line.length + 1;
    } else {
      break;
    }
  }
  
  if (kept.length < lines.length) {
    kept.push(`[... ${lines.length - kept.length} lines omitted ...]`);
  }
  
  return kept.join('\n');
}

function formatOmissionFooter(omitted: OmittedSection[], originalChars: number): string {
  if (omitted.length === 0) return '';
  
  const lines = [
    '\n\n## COMPACTION NOTICE',
    `\nOriginal prompt: ${originalChars} characters`,
    `Final prompt: ${originalChars - omitted.reduce((s, o) => s + o.originalChars, 0) + omitted.reduce((s, o) => s + (o.retainedSummary ? 100 : 0), 0)} effective characters`,
    'Omitted sections:',
    ...omitted.map(o => `- ${o.section}: ${o.originalChars} chars${o.retainedSummary ? ` (${o.retainedSummary})` : ''}`),
    'All mandatory sections retained per seat configuration.',
  ];
  
  return lines.join('\n');
}
```

```typescript
// Windows process tree termination
async function terminateProcessTree(pid: number): Promise<void> {
  if (os.platform() === 'win32') {
    // taskkill /F /T /PID <pid> kills entire tree
    const { spawn } = await import('child_process');
    return new Promise((resolve, reject) => {
      const killer = spawn('taskkill', ['/F', '/T', '/PID', pid.toString()], {
        stdio: 'ignore',
      });
      killer.on('close', (code) => {
        if (code === 0 || code === 128) { // 128 = already terminated
          resolve();
        } else {
          reject(new Error(`taskkill exited ${code}`));
        }
      });
      killer.on('error', reject);
    });
  } else {
    // POSIX: kill negative PID for process group
    try {
      process.kill(-pid, 'SIGTERM');
      // Give graceful shutdown 5s, then SIGKILL
      setTimeout(() => {
        try { process.kill(-pid, 'SIGKILL'); } catch {}
      }, 5000);
    } catch (e) {
      // Process already gone
    }
  }
}

// Error normalization
function normalizeError(error: unknown, context: string): string {
  const raw = error instanceof Error ? error.message : String(error);
  
  // Detect known internal error patterns
  if (raw.includes('"kind":"user"')) {
    return `${context}: user configuration or quota error (check seat credentials)`;
  }
  if (raw.includes('E2BIG') || raw.includes('too long')) {
    return `${context}: prompt exceeds transport limit`;
  }
  if (raw.includes('ECONNREFUSED') || raw.includes('ENOTFOUND')) {
    return `${context}: network error - seat unreachable`;
  }
  if (raw.includes('timeout') || raw.includes('ETIMEDOUT')) {
    return `${context}: deadline exceeded`;
  }
  
  // Generic but readable
  return `${context}: ${raw.slice(0, 200)}`;
}
```

```typescript
export interface LayeredTimeouts {

  if (Date.now() > timeouts.runDeadlineMs) {
    return createCancelledResult(seat, 'run deadline exceeded', prompt);
  }
  if (Date.now() > timeouts.roundDeadlineMs) {
    return createCancelledResult(seat, 'council round deadline reached', prompt);

  let lastChunkTime = Date.now();

  const timeouts: ReturnType<typeof setTimeout>[] = [];
  
  // Startup timeout

    terminateProcessTree(child.pid!).catch(() => {});

  timeouts.push(idleInterval);

    terminateProcessTree(child.pid!).catch(() => {});

  timeouts.push(seatTimeout);
  
  // Data handler updates lastChunkTime
  child.stdout?.on('data', (chunk) => {
    hasReceivedChunk = true;
    lastChunkTime = Date.now();
    // ... accumulate output ...
  });
  
  // Cleanup on completion
  const cleanup = () => {
    timeouts.forEach(t => clearTimeout(t));
    signal.removeEventListener('abort', abortHandler);
  };

}
```

### Work-package 4: Partial-result policy with quorum enforcement

```typescript
export type TerminalState = 
  | 'completed'      // quorum met, all done
  | 'partial'          // some success, below quorum, resumable
  | 'cancelled'        // user or system cancellation
  | 'failed'           // unrecoverable error
  | 'awaiting_resume'; // persisted, can continue

export interface QuorumConfig {
  draftQuorum: number;   // min successful drafts (default: ceil(seats/2))
  reviewQuorum: number;  // min successful reviews
  strict: boolean;       // if true, partial = failed
}

export function calculateQuorum(totalSeats: number): QuorumConfig {
  const min = Math.ceil(totalSeats / 2);
  return {
    draftQuorum: min,
    reviewQuorum: min,
    strict: false,
  };
}

export async function executeCouncilRound(
  round: CouncilRound,
  seats: SeatConfig[],
  signal: AbortSignal,
  journal: Journal,
  quorum: QuorumConfig,
): Promise<CouncilRoundResult> {
  const enabledSeats = seats.filter(s => round.seats.includes(s.id) && s.enabled);
  
  // Check for resumed answers first
  const resumed: CouncilResult[] = [];
  const toCall: SeatConfig[] = [];
  
  for (const seat of enabledSeats) {
    const cached = await journal.getValidReply(round, seat.id);
    if (cached && !isInvalidated(cached, round)) {
      resumed.push(cached);
    } else {
      toCall.push(seat);
    }
  }
  
  // Execute remaining seats
  const freshResults = await Promise.all(
    toCall.map(s => executeSeatWithTimeouts(s, round.prompt, signal, /* timeouts */))
  );
  
  const allResults = [...resumed, ...freshResults];
  
  // Count successes
  const successes = allResults.filter(r => r.status === 'success');
  const quorumMet = successes.length >= round.quorum;
  
  // Determine terminal state
  let state: TerminalState;
  if (signal.aborted) {
    state = 'cancelled';
  } else if (quorumMet) {
    state = 'completed';
  } else if (successes.length > 0) {
    state = 'partial';
  } else {
    state = 'failed';
  }
  
  // CRITICAL: Never report as completed without quorum
  const result: CouncilRoundResult = {
    round,
    results: allResults,
    quorumMet,
    state,
    resumedCount: resumed.length,
    calledCount: toCall.length,
  };
  
  // Persist to journal
  await journal.appendRound(result);
  
  return result;
}

// Top-level run state - ENFORCES quorum at run level
export async function executeCouncilRun(
  config: CouncilConfig,
  signal: AbortSignal,
): Promise<CouncilRun> {
  const runId = generateRunId();
  const journal = await Journal.open(runId);
  
  const run: CouncilRun = {
    runId,
    state: 'running',
    rounds: [],
    startedAt: new Date(),
  };
  
  try {
    for (const round of config.rounds) {
      // Check cancellation between rounds
      if (signal.aborted) {
        run.state = 'cancelled';
        break;
      }
      
      const roundResult = await executeCouncilRound(
        round, config.seats, signal, journal, config.quorum
      );
      
      run.rounds.push(roundResult);
      
      // Stop on failed quorum in strict mode or for planning rounds
      if (roundResult.state === 'failed' || 
          (round.phase === 'plan' && !roundResult.quorumMet)) {
        run.state = 'failed';
        break;
      }
      
      // Partial rounds allow continuation
      if (roundResult.state === 'partial') {
        run.state = 'awaiting_resume';
        // Don't break - user can resume, but we stop for now
        break;
      }
    }
    
    // Final state determination
    const allRoundsComplete = run.rounds.every(r => r.state === 'completed');
    const anyRoundFailed = run.rounds.some(r => r.state === 'failed');
```

```typescript
export class Journal {
  private entries: Map<string, JournalEntry[]> = new Map(); // phase:seat -> entries
  
  static async open(runId: string): Promise<Journal> {
    const j = new Journal(runId);
    await j.load();
    return j;
  }
  
  async getValidReply(round: CouncilRound, seatId: string): Promise<CouncilResult | null> {
    const key = `${round.phase}:${seatId}`;
    const entries = this.entries.get(key) ?? [];
    
    // Find most recent non-invalidated success
    for (const entry of entries.reverse()) {
      if (entry.status !== 'success') continue;
      
      const currentIdentity = this.computePromptIdentity(round.prompt);
      
      if (this.isInvalidated(entry, currentIdentity, round)) {
        continue;
      }
      
      // Valid cached result
      return this.entryToResult(entry);
    }
    
    return null;
  }
  
  private isInvalidated(
    entry: JournalEntry,
    currentIdentity: PromptIdentity,
    round: CouncilRound,
  ): boolean {
    // Hash mismatch = prompt changed meaningfully
    if (entry.promptIdentity.hash !== currentIdentity.hash) {
      return true;
    }
    
    // Length check catches truncation
    if (entry.promptIdentity.length !== currentIdentity.length) {
      return true;
    }
    
    // Model/transport change
    const currentSeat = round.seats.find(s => s.id === entry.seatId);
    if (!currentSeat) return true;
    
    const currentModelId = `${currentSeat.model}:${currentSeat.timeoutMs}`;
    if (entry.modelId !== currentModelId) return true;
    
    const currentTransportId = `${currentSeat.transport}:${JSON.stringify(currentSeat.cliArgs ?? currentSeat.openrouterModel ?? currentSeat.antigravitySeat)}`;
    if (entry.transportId !== currentTransportId) return true;
    
    return false;
  }
  
  private computePromptIdentity(prompt: string): PromptIdentity {
    // Normalize: collapse whitespace, but preserve structural markers
    const normalized = prompt
      .replace(/\r\n/g, '\n')
      .replace(/[ \t]+/g, ' ')
      .replace(/\n{3,}/g, '\n\n')
      .trim();
    
    // Hash the normalized content
    const hash = createHash('sha256').update(normalized).digest('hex').slice(0, 16);
    
    // Extract section keys for quick comparison
    const sectionKeys = (normalized.match(/^##? \w+/gim) ?? []).map(s => s.trim().toLowerCase());
    
    return {
      hash,
      length: normalized.length,
      sectionKeys,
    };
  }
  
  async appendRound(result: CouncilRoundResult): Promise<void> {
    // Append all results, including failures for retry tracking
    for (const r of result.results) {
      const entry: JournalEntry = {
        runId: this.runId,
        timestamp: new Date().toISOString(),
        phase: result.round.phase,
        seatId: r.seatId,
        promptIdentity: this.currentPromptIdentity!,
        modelId: `${r.transport}:`, // filled from seat config
        transportId: r.transport,
        status: r.status,
        response: r.response,
        error: r.error,
        durationMs: r.durationMs,
        isRetryable: r.status === 'timeout' || r.status === 'error',
        retryCount: 0,
        promptChars: r.promptChars,
        promptBytes: r.promptBytes,
        compactionApplied: r.compactionApplied ?? false,
        omittedSections: r.omittedSections,
      };
      
      const key = `${entry.phase}:${entry.seatId}`;
      if (!this.entries.has(key)) this.entries.set(key, []);
      this.entries.get(key)!.push(entry);
    }
    
    await this.persist();
  }
  
  // Stop does not discard - just marks interruption point
  async markInterruption(reason: string): Promise<void> {
    await this.appendMetadata({ type: 'interruption', reason, timestamp: Date.now() });
  }
}
```
