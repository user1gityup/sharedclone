pm records — types, ACLs, gates

Lead Management (Opportunity) and the Event Contact CRM (Contact Lead) are separate record types: separate tables, ids, statuses, ACLs and audit logs. A grant on one is never a grant on the other. Internal actions run without a repeat approval once granted; external ones (outbound message, export, bulk delete, third-party share) always wait for a human here. Every action below names the route that performs it, so a grant is always a grant of something that can be done — tagging and dedupe suggestions included. A type only lists an action it can carry out: the Contact Lead holds no cross-link field, so linking is an Opportunity action and is granted there. A write grant is also not a read grant — tagging, noting or linking without read returns a receipt, never the record. back to pm
